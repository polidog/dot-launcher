アイコンを並べない、文字だけのホームアプリです。ホームには大きな時計と、届いている通知、最近使ったアプリ、再生中の曲だけを出します。

■ 打てばすぐ開く
・ホームをタップか上にスワイプで検索。数文字打って Enter で起動します
・先頭一致 > 単語の頭 > 部分一致 の順に並べ、全角半角・ひらがなカタカナは区別しません（「まっぷ」で マップ）
・アプリを開くのに使った言葉は履歴に残り、次からはタップ一つで再検索できます

■ ホーム
・ドット絵の大きな時計と、和暦つきの日付
・届いている通知（タップで開く、横にスワイプで消す）
・最近使ったアプリ
・再生中の曲を画面の下に流して表示。前の曲・再生/一時停止・次の曲をホームから操作できます
・左にスワイプすると、全アプリをカテゴリ別（連絡・SNS、仕事、地図・移動、ゲームなど）に並べたページ

■ 見た目
・ライトモードは 4 階調の携帯ゲーム機の液晶風、ダークモードは黒地に白枠のゲーム風ウィンドウ
・ホームの左上で明暗を切り替え。端末の設定に合わせることもできます

■ Jev（任意・自分の API キーで使う）
TypeSafe の Jev の API キーを設定画面に入れると、次の機能が使えます。
・言葉の意味でアプリを選ぶ検索（「おんがく」で音楽アプリ、「ちず」でマップ）
・作者がカテゴリを申告していないアプリの自動カテゴリ分け
キーはご自身で typesafe.ai から取得してください。キーが無くてもランチャーとしてすべての基本機能が使えます。キーを入れたときだけ、アプリ名と検索語が TypeSafe に送られます。

■ 使う許可
・通知へのアクセス：ホームに通知と再生中の曲を出すため
・使用状況へのアクセス：最近使ったアプリを出すため
どちらも許可しなくても使えます。集めた情報を開発者が受け取ることはありません。
