# プライバシーポリシー

[English](privacy-en.md)

最終更新: 2026-10-20

DotLauncher（以下「本アプリ」）は、polidog が開発・配布する Android のホームアプリです。

## 開発者が受け取る情報

ありません。本アプリは開発者のサーバーに情報を送らず、広告や解析の SDK も入っていません。

## 端末の中だけで使う情報

次の情報は表示のために端末の中で読み、端末の外には送りません。

| 情報 | 使い道 | 必要な許可 |
| --- | --- | --- |
| インストール済みアプリの一覧 | 検索とカテゴリ別の一覧 | なし |
| 通知の内容 | ホームに通知を出す | 通知へのアクセス |
| 再生中の曲名・アーティスト名 | ホームに再生中の曲を出し、操作する | 通知へのアクセス |
| アプリの使用状況 | 最近使ったアプリを出す | 使用状況へのアクセス |
| 検索語の履歴（最大 10 件）、設定 | 次回の検索と表示 | なし |

履歴と設定は端末の中（アプリの保存領域）にだけ残り、アプリを削除すると消えます。

## TypeSafe（Jev）に送る情報

設定画面で TypeSafe の API キーを入れた場合に限り、意味での検索と自動カテゴリ分けのため、次の情報を TypeSafe の API（api.typesafe.ai）に送ります。

- インストール済みアプリの名前とパッケージ名
- 検索欄に打った言葉

送信はユーザー自身の API キーで行われ、その取り扱いは TypeSafe の利用規約とプライバシーポリシーに従います。キーを入れなければ何も送りません。キーを消せば送信は止まります。

API キーは端末の中にだけ保存します。
